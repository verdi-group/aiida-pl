# `aiida-pl`

AiiDA plugin package for calculating Photoluminescence spectra.

## Usage

Hi Mridul! 👋

After activating your Python environment and [cloning the repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository) to a local directory, enter that directory and run:

```
pip install -e .
```

to install the package and its dependencies.
I can't host the documentation online, because the repository is still private.
But you can build it locally with [Hatch](https://hatch.pypa.io/latest), a pretty neat tool for Python packaging.
You can install it globally with Homebrew:

```
brew install hatch
```

Then run the following Hatch command to serve the documentation:

```
hatch run docs:start
```

As the instructions mention, simply go to the following link once the command is running:

[http://localhost:3000](http://localhost:3000)

Let me know if you run into issues!
